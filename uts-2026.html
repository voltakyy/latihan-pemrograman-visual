SOAL 01 Bobot: 15 Poin Modul Hal. 2, 3, 7, 8 (SPADA P3 & P4)

"1. Apa yang dimaksud dengan Class dalam konsep OOP dan bagaimana hubungannya dengan Object?"

Kunci Jawaban Resmi Berdasarkan Modul Kuliah

A. Pengertian Class (Blueprint / Template)

Berdasarkan Modul Pertemuan 4 Sub-bab 2.1: Class adalah blueprint atau template untuk membuat instance object. Class menyimpan struktur data (property) dan perilaku (method). Satu class dapat digunakan untuk membuat banyak object.

Contoh pada Modul: Class: Robot adalah blueprint.

B. Pengertian Object (Instance)

Berdasarkan Modul Pertemuan 4 Sub-bab 2.2: Object adalah instance konkret yang didefinisikan oleh class. Banyak object dapat dibuat dari satu class yang sama. Setiap object dapat memiliki nilai property yang berbeda, meskipun berasal dari class yang sama (misalnya warna, posisi, ukuran, orientasi).

Contoh pada Modul: Dari satu Class Robot, dibuat tiga object: Robot A, Robot B, dan Robot C.

C. Hubungan Class dan Object (One Class ➔ Many Objects)

Hubungan keduanya terlihat langsung pada lingkungan visual Alice 3:

  • Class berada di Gallery (contoh: Class Bunny di Gallery hanya ada 1).
  • Object berada di Scene (contoh: dari 1 Class Bunny, ditambahkan ke scene menjadi object bunny, bunny2, dan bunny3).
  • Same Class, Different Objects: Objek bunny dan bunny2 berasal dari class yang sama, namun memiliki nilai property yang berbeda:
    • position: bunny di (0, 0, 0) sedangkan bunny2 di (2, 0, -1).
    • color: bunny default/putih sedangkan bunny2 biru.
    • size: bunny 1.0 sedangkan bunny2 1.5.
SOAL 02 Bobot: 15 Poin Modul Hal. 4, 9, 10, 11, 12 (SPADA P3 & P4)

"2. Apa yang dimaksud dengan State (Property) dan Behavior (Method) pada sebuah object? Jelaskan!"

Kunci Jawaban Resmi Berdasarkan Modul Kuliah

A. State (Property) — Apa yang Dimiliki Object

Berdasarkan Modul Pertemuan 4 Sub-bab 3.1: Property adalah data atau keadaan object.

  • Menunjukkan apa yang dimiliki oleh object.
  • Menyimpan informasi atau keadaan (state) object.
  • Setiap object dapat memiliki nilai property yang berbeda dan nilainya dapat berubah selama program berjalan.
  • Di Alice 3, property dikelola pada panel Properties.
  • Contoh Property pada Modul:
    • color ➔ biru / default
    • position ➔ (0, 0, 0)
    • direction / orientation ➔ 0° (menghadap depan) / 90°
    • speed ➔ 1.0
    • size ➔ 1.5

B. Behavior (Method) — Apa yang Dapat Dilakukan Object

Berdasarkan Modul Pertemuan 4 Sub-bab 3.2: Method adalah perilaku object.

  • Menunjukkan apa yang dapat dilakukan oleh object (merupakan aksi yang dapat dilakukan object).
  • Method dijalankan untuk menghasilkan behavior.
  • Di Alice 3, method disusun di Code Editor.
  • Method dapat memiliki informasi tambahan yang disebut argument / parameter (seperti direction, steps, degrees, revolutions).
  • Contoh Method pada Modul (Object Bunny):
    • move() ➔ menggerakkan object (contoh: bunny.move(FORWARD, 2))
    • turn() ➔ memutar object (contoh: bunny.turn(RIGHT, 0.25) di mana 0.25 revolutions ≈ 90°)
    • jump() ➔ melompat
    • say() ➔ menampilkan balon teks pesan (contoh: bunny.say("Hello!"))
    • stop() ➔ menghentikan gerakan

C. Hubungan Property dan Method Menghasilkan Behavior

Beberapa method dapat disusun secara berurutan (sequence) untuk membentuk perilaku (behavior) yang lebih kompleks.
Alur Konsep: Class ➔ membuat (create) ➔ Object ➔ memiliki ➔ Property + Method ➔ menghasilkan ➔ Behavior.

SOAL 04 Bobot: 15 Poin Modul Pertemuan 5 & 6 (Procedural Abstraction)

"4. Apa yang dimaksud dengan procedure dan mengapa procedure diperlukan dalam pengembangan program?"

Kunci Jawaban Resmi Berdasarkan Modul Kuliah

A. Pengertian Procedure:

Berdasarkan Modul Pertemuan 5 & 6: Procedure adalah subrutin atau kumpulan instruksi yang dikelompokkan bersama untuk menjalankan suatu aksi atau perilaku tertentu (misalnya animasi gerak atau perubahan visual) tanpa mengembalikan nilai hasil (return type void).
Contoh pada Modul: Pembuatan procedure jump() pada Bunny / MarchHare untuk mengemas gerakan melompat.

B. Mengapa Procedure Diperlukan dalam Pengembangan Program?

  1. Procedural Abstraction (Penyederhanaan):
    Sekumpulan instruksi rumit dapat dikelompokkan menjadi sebuah procedure (seperti jump()), sehingga pemanggil cukup memanggil satu baris instruksi tanpa perlu menuliskan detail instruksi yang sama secara berulang.
  2. Code Reusability (Dapat Digunakan Kembali):
    Procedure yang telah dibuat dapat dipanggil berulang kali di berbagai scene atau diwariskan ke objek lain (misal ditempatkan di class Biped agar bisa dipakai Bunny dan MarchHare).
  3. Modularitas & Maintainability:
    Jika terdapat perbaikan pada gerakan animasi, programmer cukup memperbaiki kode di dalam procedure tersebut tanpa merusak alur program utama.
  4. Mendukung Parameter:
    Procedure dapat dikembangkan menjadi jump(direction) dengan menambahkan parameter untuk menghasilkan variasi behavior berdasarkan input yang diberikan.

SOAL 06 Bobot: 20 Poin Modul Hal. 18–21 (P4), P6 (Biped), & Slide Netlify (P7)

"6. Apa yang dimaksud dengan Inheritance dalam OOP dan kenapa konsep ini sangat bermanfaat? Berikan contohnya dari modul!"

Kunci Jawaban Resmi Berdasarkan Modul Kuliah

A. Pengertian Inheritance (Pewarisan)

Berdasarkan Modul Pertemuan 4 Sub-bab 21 & Slide Kuliah Netlify: Inheritance adalah mekanisme ketika Child Class (Subclass) mewarisi property dan method dari Parent Class (Superclass), kemudian dapat menambahkan behavior khususnya sendiri.

B. Contoh Struktur Inheritance pada Modul:

  • 1. Hierarki Animal (Modul Hal. 19–21):
    Parent Class: Animal memiliki property name, position dan method move().
    • Child Class Bird mewarisi name, position, move() + specific method fly().
    • Child Class Rabbit mewarisi name, position, move() + specific method jump().
    • Child Class Fish mewarisi name, position, move() + specific method swim().
  • 2. Hierarki Alice 3 (Pertemuan 6):
    Class Biped adalah Parent Class, sedangkan Bunny dan MarchHare adalah Child Class. Procedure jump() ditempatkan pada class Biped sehingga dapat diwarisi dan digunakan oleh keduanya.
  • 3. Final Challenge Penguin (Modul Hal. 24):
    Class Penguin mewarisi move() dan turn() dari Parent Class Animal/Biped, serta menambahkan specific method waddle() (jalan bergoyang).
  • 4. Sintaks Java OOP (Slide Netlify):
    extends & super (Netlify Slide 3, 6, 11) 
    // Keyword 'extends' menyatakan hubungan inheritance
class Vehicle {
    void move() { System.out.println("Moving"); }
}

class Car extends Vehicle {
    @Override
    void move() { System.out.println("Driving"); }

    void start() {
        super.move(); // Keyword 'super' memanggil method parent
    }
}

new Car().start(); // Output: Moving

C. Mengapa Inheritance Sangat Bermanfaat? (3 Keuntungan Utama pada Modul)

  1. Tidak perlu menulis ulang property dan method yang sama (menghindari duplikasi / DRY).
  2. Kode lebih rapi dan mudah dipelihara (perubahan pada superclass otomatis diwarisi seluruh subclass).
  3. Setiap Child Class tetap bisa memiliki behavior khusus (seperti burung bisa fly, kelinci bisa jump, dan penguin bisa waddle).

Visualizer Alur Eksekusi: Alice 3 ke Java OOP

Pelajari bagaimana hierarki visual di Alice 3 diterjemahkan ke sintaks Java murni dengan keyword extends dan super.

1. HIERARKI ALICE 3 VISUAL MODEL
SJointedModel
  └── Biped (Parent Class)
       ├── Bunny (Child Class 1)
       └── MarchHare (Child Class 2)

Procedure jump() yang diletakkan pada class Biped otomatis diwarisi oleh Bunny dan MarchHare tanpa perlu membuat ulang di kedua class anak.

2. SINTAKS JAVA OOP NETLIFY DOSEN
class Biped extends SJointedModel {
  void jump() { ... }
}
class Bunny extends Biped {
  @Override
  void jump() {
    super.jump(); // panggil aksi parent
    System.out.println("Telinga goyang");
  }
}

Menggunakan extends untuk mewarisi dan super.jump() untuk memanggil implementasi method parent saat terjadi method overriding.

RINGKASAN RESMI UTS PEMROGRAMAN VISUAL 2026/2027

Teknik Informatika Universitas Muhammadiyah Surakarta · Sesuai PRD & Modul Kuliah

1. CLASS & OBJECT
• Class: Blueprint / template (contoh: Class Robot, Gallery Bunny).
• Object: Instance nyata (Robot A, B, C / Scene bunny, bunny2).
• Same Class Different Objects: Beda position, orientation, size, color.
2. PROPERTY & METHOD
• Property: Data/keadaan (what it has: color, position, speed, size).
• Method: Perilaku/aksi (what it does: move, turn, jump, say).
• Parameter: Direction, Steps, Revolutions (0.25 rev ≈ 90°).
3. SEQUENCE & KONTROL
• Sequence: Susunan instruksi membentuk behavior.
• do in order: Berurutan satu per satu.
• do together: Bersamaan / simultan.
• count up to: Counted loop | while: Conditional loop.
4. PROCEDURE VS FUNCTION
• Procedure: Aksi murni / void (contoh: bunny.jump()).
• Function: Ada nilai balik (contoh: getDistanceTo()).
• Procedural Abstraction: Mengemas instruksi rumit jadi jump().
5. HIERARCHY & INHERITANCE
• Superclass Animal: Diwarisi Bird (fly), Rabbit (jump), Fish (swim).
• Biped: Diwarisi Bunny & MarchHare.
• Penguin: Inherited move/turn + Specific waddle().
6. EXTENDS & SUPER (JAVA)
• extends: Deklarasi pewarisan (Car extends Vehicle).
• super.method(): Panggil method parent saat override.
• super(): Panggil constructor parent.
• super.field: Akses atribut parent yang shadowed.
