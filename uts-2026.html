PERTEMUAN 1 & 2

Introduction to Visual Programming — From Instructions to Visual Blocks

Fondasi Logika

Pemrograman pada hakikatnya bukan sekadar menghafal sintaks kode, melainkan proses merancang solusi komputasi yang terstruktur. Komputer memerlukan instruksi yang eksplisit, terstruktur, memiliki urutan yang jelas, dan tidak ambigu.

  • Tahapan Penyelesaian Masalah: Masalah ➔ Algoritma ➔ Instruksi ➔ Program ➔ Output.
  • 5 Bentuk Representasi Logika: Bahasa Natural, Pseudocode, Flowchart (diagram alir), Kode Tekstual (Java, Python, C++), dan Blok Visual (Alice 3).
  • Tekstual vs Visual: Keduanya memakai logika algoritma yang sama persis. Pendekatan visual dipakai sebagai fondasi awal agar mahasiswa memahami urutan, kondisi, dan objek sebelum berpindah ke pemrograman tekstual.
PERTEMUAN 3

Dari Instruksi Menuju Object dan Class

Transisi ke Objek

Sebuah program dapat dipandang sebagai kumpulan objek yang berinteraksi. Setiap objek memiliki data (property) dan aksi (method):

  • Object & Behavior: Objek adalah entitas yang menerima instruksi dan menghasilkan perilaku tertentu.
  • Sequence (Urutan): Urutan penyusunan instruksi secara langsung menentukan hasil akhir program. Urutan yang salah menghasilkan perilaku yang salah.
  • Property (Keadaan/State): Data ciri objek, seperti color, position (x, y, z), orientation (sudut hadap), dan speed.
  • Method: Aksi yang dapat dilakukan objek, seperti move(), turn(), stop(), say().
  • Class: Blueprint / cetak biru / template yang mendefinisikan struktur property dan method.
  • One Class, Many Objects: Dari 1 class (misal Class Robot), dapat dibuat banyak objek (Robot A, Robot B, Robot C) dengan nilai property yang berbeda-beda.

PERTEMUAN 5

Praktikum Mandiri Alice 3 — Control Statements & Animasi Bunny

Struktur Kontrol

Mengembangkan animasi Bunny dan MarchHare menggunakan struktur kendali eksekusi:

  • do in order: Blok kontrol default di mana instruksi dieksekusi secara berurutan satu demi satu dari atas ke bawah.
  • do together: Blok kontrol di mana beberapa instruksi dijalankan secara bersamaan (simultan) (contoh: mengayunkan kedua tangan dan kaki sekaligus saat melompat).
  • count up to (Counted Loop): Mengeksekusi perulangan sebanyak n kali hitungan pasti.
  • while (Conditional Loop): Mengeksekusi perulangan selama kondisi logika tertentu masih bernilai true.
  • Membuat Procedure jump(): Mengemas gerakan lompat (gerak ke atas lalu turun) menjadi satu procedure mandiri agar reusable.
PERTEMUAN 6

From Procedural Abstraction to Inheritance, Parameters & Functions

Abstraksi & Fungsi

Menyempurnakan program animasi agar lebih modular dan fleksibel:

  • 1. Procedural Abstraction: Mengelompokkan rangkaian instruksi kompleks menjadi satu nama prosedur ringkas (seperti jump()), sehingga pemanggil tidak perlu tahu kerumitan di dalamnya.
  • 2. Inheritance di Alice 3 (Biped Hierarchy): Procedure jump() yang dibuat pada level parent class Biped otomatis diwarisi dan bisa dipakai oleh Bunny maupun MarchHare.
  • 3. Parameter pada Procedure: Mengembangkan prosedur menjadi jump(direction, distance) agar bisa melompat ke arah dan jarak yang dinamis.
  • 4. Procedure vs Function: Procedure bertugas menjalankan aksi (void), sedangkan Function bertugas mengembalikan nilai (misal fungsi bawaan Alice getDistanceTo() untuk mengukur jarak).
PERTEMUAN 7 (NETLIFY)

Pewarisan Java OOP: Keyword extends & super

Transisi ke Java

Materi resmi dari slide kuliah dosen (https://extends-super-inheritance.netlify.app/) untuk menghubungkan hierarki visual Alice ke bahasa Java murni:

  • Koneksi Alice ke Java:
    class Biped extends SJointedModel { ... }
    class Bunny extends Biped { ... }
  • Keyword extends: Menyatakan hubungan pewarisan bahwa subclass mewarisi anggota superclass (contoh: class Dog extends Animal).
  • Pemanggilan Inherited Method: Method warisan (seperti move()) dapat dipanggil langsung oleh objek anak (dog1.move()) tanpa perlu kata kunci tambahan.
  • Method Overriding: Ketika subclass menulis ulang method dengan nama dan signature yang sama dengan superclass (ditandai anotasi @Override).
  • Keyword super:
    1. Method: super.sound() memanggil implementasi method milik superclass.
    2. Constructor: super("Buddy") memanggil constructor superclass untuk inisialisasi data parent.
    3. Field: super.name mengakses atribut parent yang tertutup (shadowed) oleh atribut anak this.name.
  • Miskonsepsi Penting: super TIDAK selalu wajib dipakai saat inheritance. Method warisan dapat dipanggil langsung secara normal jika tidak di-override.
SOAL 01 Bobot: 15 Poin SPADA P1 & P2

"Jelaskan alur penyelesaian masalah komputasi dari Masalah hingga menjadi Program yang dapat dipahami komputer! Mengapa instruksi harus bersifat terstruktur dan tidak ambigu?"

Kunci Jawaban Sempurna

1. Alur 5 Tahapan:

Masalah ➔ Algoritma ➔ Instruksi ➔ Program ➔ Output

  • Masalah: Situasi atau tantangan komputasi nyata yang ingin diselesaikan.
  • Algoritma: Urutan langkah logis dan sistematis untuk memecahkan masalah.
  • Instruksi: Perintah satuan yang dapat diterjemahkan ke dalam bahasa mesin.
  • Program: Kumpulan instruksi utuh yang disusun dalam bahasa pemrograman (tekstual/visual).
  • Output: Hasil akhir yang ditampilkan atau dijalankan oleh komputer.

2. Mengapa Harus Terstruktur dan Tidak Ambigu?

Komputer adalah mesin deterministik yang tidak memiliki intuisi manusia. Komputer mengeksekusi instruksi secara harfiah. Jika instruksi ambigu atau urutannya keliru, komputer akan menghasilkan kesalahan logika (logic error) atau program berhenti tiba-tiba (crash).

SOAL 03 Bobot: 15 Poin SPADA P3 & P4

"Apa yang dimaksud dengan Parameter pada sebuah method di Alice 3? Berikan contohnya dan jelaskan apa yang terjadi jika parameter diubah!"

Kunci Jawaban Sempurna

1. Pengertian Parameter:

Parameter adalah informasi tambahan yang dikirimkan ke dalam sebuah method untuk menentukan secara spesifik bagaimana aksi tersebut dijalankan oleh objek.

2. Contoh Parameter di Alice 3:

  • Direction: Menentukan arah pergerakan (FORWARD, BACKWARD, LEFT, RIGHT).
  • Distance / Steps: Menentukan seberapa jauh objek bergerak (misal 2.0 meter).
  • Revolutions / Degrees: Menentukan besar putaran objek (misal 0.25 revolutions ekuivalen dengan 90 derajat putaran).

3. Dampak Jika Parameter Diubah:

Mengubah nilai parameter akan mengubah hasil perilaku (*behavior*) objek secara langsung. Contoh: jika turn(RIGHT, 0.25) diubah menjadi turn(LEFT, 0.5), maka objek yang tadinya berbelok ke kanan 90° akan berputar ke kiri 180° menghadap ke belakang.

SOAL 05 Bobot: 15 Poin SPADA P5

"Jelaskan perbedaan mendasar antara struktur kontrol 'do in order' dan 'do together' di Alice 3, serta sebutkan kapan masing-masing digunakan!"

Kunci Jawaban Sempurna

1. do in order (Sekuensial):

Mengeksekusi setiap baris instruksi di dalamnya secara berurutan satu demi satu dari atas ke bawah. Baris kedua baru akan berjalan setelah baris pertama tuntas.

2. do together (Simultan / Paralel):

Mengeksekusi semua instruksi di dalamnya secara bersamaan dalam satu waktu.
Penggunaan: Animasi realistis (Saat karakter melompat: badan terangkat ke atas move(UP) bersamaan dengan kedua kaki ditekuk).

SOAL 06 Bobot: 10 Poin SPADA P6

"Apa itu Procedural Abstraction dan bagaimana hubungannya dengan Procedure vs Function di Alice 3?"

Kunci Jawaban Sempurna

1. Procedural Abstraction:

Teknik menyembunyikan detail kerumitan langkah-langkah instruksi di dalam satu nama prosedur (seperti jump()). Pengguna prosedur cukup memanggil namanya tanpa perlu mengetahui 10 baris kode detail di dalamnya.

2. Perbedaan Procedure vs Function:

  • Procedure: Berorientasi pada aksi nyata / animasi / perubahan visual (bertipe void / tanpa nilai balik). Contoh: bunny.jump().
  • Function: Berorientasi pada komputasi / menjawab pertanyaan dengan mengembalikan data hasil. Contoh: bunny.getDistanceTo(marchHare) yang mengembalikan angka desimal (Double).
SOAL 07 Bobot: 15 Poin SPADA P7 & Netlify Dosen

"Jelaskan fungsi keyword 'extends' dan 'super' dalam pemrograman berorientasi objek Java! Berikan contoh pemanggilan constructor dan method overriding!"

Kunci Jawaban Sempurna (Sesuai Slide Dosen Netlify)

1. Keyword extends:

Digunakan untuk mendeklarasikan hubungan pewarisan bahwa suatu class adalah subclass dari superclass. Subclass otomatis mewarisi seluruh atribut dan method non-private parent class.

Contoh extends & super 
class Vehicle {
    String brand;
    Vehicle(String brand) { this.brand = brand; }

    void move() { System.out.println("Moving"); }
}

class Car extends Vehicle {
    Car(String brand) {
        super(brand); // 1. super() memanggil constructor parent
    }

    @Override
    void move() {
        System.out.println("Driving");
    }

    void start() {
        super.move(); // 2. super.move() memanggil implementasi method parent
    }
}

2. Tiga Kegunaan Utama super:

  1. super.method(): Memanggil implementasi method milik superclass saat method tersebut di-override oleh anak.
  2. super(arguments): Memanggil constructor superclass yang sesuai untuk inisialisasi state parent.
  3. super.field: Mengakses atribut parent jika terdapat nama atribut yang sama persis di subclass (shadowed).

Visualizer Alur Eksekusi: Alice 3 ke Java OOP

Pelajari bagaimana hierarki visual di Alice 3 diterjemahkan ke sintaks Java murni dengan keyword extends dan super.

1. HIERARKI ALICE 3 VISUAL MODEL
SJointedModel
  └── Biped (Parent)
       ├── Bunny (Child 1)
       └── MarchHare (Child 2)

Procedure jump() yang diletakkan pada class Biped otomatis diwarisi oleh Bunny dan MarchHare tanpa perlu membuat ulang di kedua class anak.

2. SINTAKS JAVA OOP NETLIFY DOSEN
class Biped extends SJointedModel {
  void jump() { ... }
}
class Bunny extends Biped {
  @Override
  void jump() {
    super.jump(); // panggil aksi parent
    System.out.println("Telinga goyang");
  }
}

Menggunakan extends untuk mewarisi dan super.jump() untuk memanggil implementasi method parent saat terjadi method overriding.
