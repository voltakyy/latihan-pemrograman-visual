SOAL 01 Bobot: 15 Poin Class & Object Concept

"Apa yang dimaksud dengan Class dalam konsep OOP dan bagaimana hubungannya dengan Object?"

Pembahasan Lengkap & Model Jawaban Dosen

1. Pengertian Class dalam OOP

Class adalah sebuah blueprint (cetak biru), kerangka dasar, prototipe abstrak, atau spesifikasi tipe data bentukan programmer yang mendefinisikan struktur data (properties/atribut/state) dan sekumpulan tindakan (methods/behavior) yang akan dimiliki oleh objek-objek sejenis.

Secara teknis, deklarasi sebuah class belum mengalokasikan ruang memori fisik (Heap memory) untuk data objek. Class hanya berperan sebagai rancangan logis.

2. Hubungan Antara Class dan Object

Hubungan antara Class dan Object adalah hubungan antara cetakan dengan produk hasil cetakan (relasi Type to Instance):

  • Class sebagai Definisi: Menentukan "apa saja yang boleh dimiliki dan dilakukan" oleh objek.
  • Object sebagai Wujud Nyata (Instance): Entitas konkret yang benar-benar hidup di memori komputer, diciptakan melalui proses instansiasi (menggunakan operator new pada Java atau menambahkan model ke dunia 3D di Alice 3).
  • Relasi Satu-ke-Banyak (1 to N): Dari satu class yang sama, kita bisa menciptakan banyak object mandiri yang memiliki nilai atribut berbeda-beda tanpa saling mengganggu.

3. Analogi Dunia Nyata & Implementasi Kode

Analogi: Denah arsitektur rumah (Class) vs Bangunan rumah fisik yang dihuni di jalan Mawar No. 10 (Object). Dari satu lembar denah, kontraktor bisa membangun 50 rumah dengan warna cat dan furnitur yang berbeda.

Contoh Hubungan Class & Object 
// CLASS: Cetak Biru
class Mobil {
    String merk;
    String warna;
    void melaju() { System.out.println(merk + " melaju!"); }
}

// OBJECT: Dua Instance Berbeda dari Class yang Sama
Mobil mobilA = new Mobil(); // Object 1 di memori Heap
mobilA.merk = "Avanza";

Mobil mobilB = new Mobil(); // Object 2 di memori Heap
mobilB.merk = "Brio";
SOAL 02 Bobot: 15 Poin State & Behavior

"Apa yang dimaksud dengan State (Property) dan Behavior (Method) pada sebuah object? Jelaskan hubungannya!"

Pembahasan Lengkap & Model Jawaban Dosen

1. Pengertian State (Property / Field / Atribut)

State (Property) adalah kondisi data, ciri-ciri, atau variabel internal yang melekat dan disimpan di dalam sebuah objek pada suatu momen tertentu. State merepresentasikan "apa yang dimiliki (what it has)" atau status keadaan objek tersebut.

Nilai state dapat bersifat konstan atau berubah-ubah selama program berjalan sebagai akibat dari tindakan method. Contoh pada objek Lampu: state isMenyala = false, dayaWatt = 15.

2. Pengertian Behavior (Method / Operasi)

Behavior (Method) adalah sekumpulan instruksi, fungsi, atau prosedur di dalam class yang mendefinisikan tindakan atau aksi yang dapat dilakukan oleh atau terhadap objek tersebut. Behavior merepresentasikan "apa yang bisa dilakukan (what it does)".

Contoh pada objek Lampu: method saklarOn(), saklarOff(), gantiBohlam().

3. Hubungan Timbal Balik Antara State dan Behavior

State dan Behavior saling terikat secara intim dalam prinsip Encapsulation:

  • Behavior mengubah State: Ketika method saklarOn() dijalankan, ia mengubah nilai state isMenyala dari false menjadi true.
  • State menentukan hasil Behavior: Jika state bensin mobil volumeBensin == 0, maka method tancapGas() tidak akan bisa dijalankan (menolak melaju).
SOAL 03 Bobot: 15 Poin Pemodelan Behavior Manusia

"Berikan contoh behavior (method) manusia dalam pemodelan OOP beserta penjelasan fungsi dan pengaruhnya terhadap state!"

Pembahasan Lengkap & Model Jawaban Dosen

1. Pemodelan Class Manusia

Jika seorang manusia dimodelkan ke dalam class OOP, ia memiliki state (seperti nama, usia, energi, tingkatKenyang, pengetahuan). Behavior adalah seluruh tindakan yang bisa dilakukan manusia tersebut:

2. Contoh 5 Behavior Konkret Manusia

  1. berjalan(int jarakMeter)
    Fungsi: Menggerakkan tubuh manusia berpindah posisi sejauh jarak tertentu.
    Pengaruh State: Mengurangi nilai energi (misal berkurang 5 poin per 100 meter) dan menambah kelelahan.
  2. makan(String makanan, int kalori)
    Fungsi: Mengonsumsi makanan untuk metabolisme tubuh.
    Pengaruh State: Meningkatkan tingkatKenyang dan memulihkan poin energi.
  3. tidur(int durasiJam)
    Fungsi: Mengistirahatkan raga dan pikiran.
    Pengaruh State: Mereset status lelah, memulihkan energi = 100, dan memelihara kesehatan.
  4. belajar(String materi)
    Fungsi: Membaca buku atau menyimak penjelasan dosen.
    Pengaruh State: Meningkatkan state pengetahuan atau IPK, namun mengonsumsi sedikit energi.
  5. berbicara(String pesan)
    Fungsi: Menyampaikan komunikasi lisan kepada manusia lain (ekuivalen dengan say() pada Alice 3).
Manusia.java (State & Behavior Hubungan Nyata) 
public class Manusia {
    // STATE (Property)
    String nama;
    int energi = 100;
    int tingkatKenyang = 50;

    // BEHAVIOR (Method)
    void makan(String makanan) {
        tingkatKenyang += 30;
        energi += 20;
        System.out.println(nama + " makan " + makanan + ". Energi naik menjadi: " + energi);
    }

    void berjalan(int langkah) {
        if (energi <= 10) {
            System.out.println(nama + " terlalu lemas untuk berjalan!");
            return;
        }
        energi -= (langkah / 100);
        System.out.println(nama + " berjalan " + langkah + " langkah. Sisa energi: " + energi);
    }
}
SOAL 04 Bobot: 15 Poin Prosedur & Rekayasa Program

"Apa yang dimaksud dengan procedure dan mengapa procedure sangat diperlukan dalam pengembangan program?"

Pembahasan Lengkap & Model Jawaban Dosen

1. Pengertian Procedure

Procedure (Prosedur) adalah subrutin, blok kode, atau subprogram terisolasi yang berisi sekumpulan instruksi terstruktur untuk menjalankan suatu aksi atau tugas tertentu tanpa mengembalikan nilai (return value) kepada pemanggilnya. Pada bahasa pemrograman seperti Java/C++, prosedur ditandai dengan return type void.

2. Mengapa Procedure Sangat Diperlukan? (4 Alasan Krusial)

  • 1. Modularitas (Divide and Conquer):
    Mengurai program yang raksasa dan rumit menjadi modul-modul kecil yang mandiri. Hal ini memudahkan kolaborasi tim pengembang perangkat lunak karena programmer dapat membagi tugas pengerjaan per prosedur.
  • 2. Menghindari Duplikasi Kode (Prinsip DRY — Don't Repeat Yourself):
    Instruksi yang sering dipakai (seperti mencetak struk belanja, menggerakkan karakter maju, atau validasi input) cukup ditulis 1 kali saja di dalam prosedur, lalu dipanggil di berbagai tempat kapan pun dibutuhkan.
  • 3. Kemudahan Debugging dan Perawatan (Maintainability):
    Jika terdapat kesalahan logika (bug) atau perubahan aturan bisnis, kita cukup memperbaiki kode di dalam satu blok prosedur tersebut tanpa risiko merusak bagian kode lainnya.
  • 4. Meningkatkan Keterbacaan Kode (Readability):
    Alur program utama menjadi sangat bersih dan deskriptif karena menggunakan nama prosedur yang bermakna (contoh: nyalakanMesin();, bacaSensor();, simpanData();).
SOAL 05 Bobot: 20 Poin Procedure vs Function

"Jelaskan perbedaan mendasar antara procedure dan function dalam pemrograman beserta contohnya!"

Pembahasan Lengkap & Model Jawaban Dosen

1. Matriks Perbedaan Procedure vs Function

Kriteria Pembeda Procedure (Prosedur) Function (Fungsi)
Nilai Balik (Return Value) TIDAK MENGEMBALIKAN NILAI (bertipe void). WAJIB MENGEMBALIKAN NILAI (bertipe int, double, boolean, String, dll).
Tujuan Pokok Menghasilkan aksi fisik, animasi gerak, perubahan status, atau input/output di layar. Menghitung rumus matematika, mencari data, atau mengecek status kondisi logika.
Cara Pemanggilan Berdiri sendiri sebagai satu baris instruksi utuh (statement). Harus ditampung ke dalam variabel, dipakai dalam rumus, atau sebagai syarat percabangan (if).
Contoh di Alice 3 alice.move(FORWARD, 2.0);
alice.say("Halo!");		 alice.getDistanceTo(kelinci);
alice.getHeight();
Contoh di Java void cetakHeader() { ... } double hitungLuas(double r) { return 3.14 * r * r; }

2. Mengapa Function Bisa Masuk ke Kondisi IF sedangkan Procedure Tidak?

Karena function menghasilkan nilai (misalnya Boolean: true/false atau angka), nilai tersebut dapat dievaluasi oleh operator relasional. Sedangkan procedure hanya melakukan aksi (bertipe void/hampa), sehingga jika ditulis if (alice.move(...)) komputer akan memunculkan error "incompatible types: void cannot be converted to boolean".

SOAL 06 Bobot: 20 Poin Inheritance & Kebermanfaatan

"Apa yang dimaksud dengan Inheritance dalam OOP dan mengapa konsep ini sangat bermanfaat dalam rekayasa perangkat lunak?"

Pembahasan Lengkap & Model Jawaban Dosen

1. Pengertian Inheritance (Pewarisan)

Inheritance (Pewarisan) adalah pilar fundamental OOP yang memungkinkan sebuah class baru (disebut subclass / child class / kelas turunan) mewarisi atribut (state) dan metode (behavior) dari class yang sudah ada sebelumnya (disebut superclass / parent class / kelas induk).

Inheritance membentuk relasi hierarkis "is-a" (adalah seorang / adalah sebuah). Contoh:

  • Mahasiswa is-a Manusia
  • Petani is-a Manusia
  • Kucing is-a Hewan

2. Mengapa Inheritance Sangat Bermanfaat? (4 Manfaat Utama)

  • 1. Reusabilitas Kode yang Sangat Tinggi (Code Reusability):
    Atribut umum seperti nama, usia, gender, alamat serta method berjalan(), makan() cukup ditulis satu kali di class parent Manusia. Subclass tidak perlu menulis ulang, melainkan otomatis mewarisinya.
  • 2. Menghilangkan Redundansi (DRY Principle):
    Mencegah pemborosan baris kode dan menghemat konsumsi memori. Jika terdapat 10 jenis profesi manusia, kita menghemat puluhan deklarasi variabel duplikat.
  • 3. Kemudahan Pemeliharaan Skala Besar (Scalability & Maintainability):
    Jika ada atribut umum baru (misalnya pemerintah menambahkan nik atau kewarganegaraan), kita cukup menambahkannya di Manusia satu kali saja, dan seluruh subclass otomatis memiliki atribut tersebut.
  • 4. Mendukung Polimorfisme & Overriding:
    Subclass dapat memodifikasi (meng-override) method warisan jika ingin memberikan perilaku khusus (misalnya method makan() pada Mahasiswa disesuaikan menjadi makan di kantin kampus).

*Bisa dimasukkan ke dalam ekspresi if (jarak < 2.0).

LEMBAR BELAJAR CEPAT UTS PEMROGRAMAN VISUAL 2026/2027

Informatika Universitas Muhammadiyah Surakarta

1. CLASS VS OBJECT
• Class: Blueprint / cetak biru, belum ada memori fisik.
• Object: Wujud konkret (instance), dibuat dengan new di memori Heap.
• Relasi: 1 Class dapat mencetak banyak Object dengan state berbeda.
2. STATE VS BEHAVIOR
• State (Property): Variabel / data ciri objek ("apa yang dimiliki").
• Behavior (Method): Aksi / fungsi ("apa yang bisa dilakukan").
• Saling memengaruhi: Method berjalan() mengubah state energi.
3. BEHAVIOR MANUSIA (OOP)
• berjalan(jarak) ➔ kurangi energi.
• makan(kalori) ➔ pulihkan energi & kenyang.
• tidur(jam) ➔ reset stamina 100%.
• belajar(topik) ➔ tambah pengetahuan & IPK.
4. PERAN PROCEDURE
Blok kode mandiri bertipe void (tanpa return).
• Modularitas: Pecah program besar jadi modul kecil.
• DRY Principle: Hindari penulisan kode berulang.
• Maintainability: Debugging dan perbaikan terisolasi.
5. PROCEDURE VS FUNCTION
• Procedure: Aksi murni / animasi / void (contoh: alice.move()).
• Function: Ada nilai balik / return (contoh: alice.getDistanceTo()).
• Function dapat masuk ke rumus & syarat if.
6. INHERITANCE (PEWARISAN)
• Relasi "is-a": Subclass mewarisi state & behavior dari Superclass.
• Manfaat: Code reusability tinggi, hemat baris kode (DRY), mudah dirawat, mendukung polymorphism.
