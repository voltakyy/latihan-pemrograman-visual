# Ruang Visual — Latihan UTS Pemrograman Visual

Latihan soal pilihan ganda untuk UTS Pemrograman Visual: **Class & Object**, **Property & Method**, **Inheritance**, **Function & Procedure**, dan **Perulangan**.

- 31 soal: 23 soal inti + 8 soal tantangan
- Pembahasan panjang di setiap soal
- Urutan soal dan pilihan jawaban diacak
- Bisa dijawab dengan klik, tombol **1–4 / A–D**, lalu **Enter** untuk lanjut
- Rapor per topik, review jawaban salah, dan rekor tersimpan di browser

## Halaman Khusus Latihan UTS 2026 (Terbaru)

Buka [`uts-2026.html`](uts-2026.html) untuk belajar dan latihan soal prediksi serta pembahasan mendalam **UTS Gasal 2026/2027**:
- **6 Pilar Soal Inti:** Class vs Object, State & Behavior, Behavior Manusia, Kebutuhan Procedure di Software Engineering, Alice 3 Procedure vs Function, dan Kebermanfaatan Inheritance (Relasi "is-a").
- **Arena Simulasi Esai & Self-Scoring:** Penilaian mandiri (0–100 Poin) lengkap dengan rubrik dosen dan auto-save `localStorage`.
- **Kuis 10 Kasus & Jebakan Konseptual:** Latihan pilihan ganda interaktif dengan feedback langsung.
- **Visualizer Alur Data Alice 3:** Perbandingan eksekusi Procedure vs Function.
- **Rangkuman Catatan A4:** Siap cetak / simpan PDF (`Ctrl + P`).

## Halaman Khusus UTS 2024 (Naskah Asli UMS)

Buka [`uts-2024.html`](uts-2024.html) untuk belajar dan latihan langsung dari naskah ujian resmi **UTS Gasal 2024/2025 (Senin, 04 November 2024)**:
- **Bedah Tuntas 5 Soal Esai:** Solusi ideal 100% dosen untuk Class vs Object, Property & Method (minimal 4), Rekonstruksi Diagram UML Inheritance (Mahasiswa, Petani, Pedagang), Alice 3 Functions vs Procedures, dan Perulangan.
- **Arena Latihan & Simulasi Esai:** Tempat mengetik jawaban sendiri, kalkulator skor mandiri (0–100 Poin), dan rubrik penilaian dosen.
- **Kuis 10 Kasus & Jebakan UTS:** Latihan soal pilihan ganda interaktif dengan feedback langsung.
- **Visualizer Diagram UML:** Membandingkan diagram sebelum vs sesudah inheritance secara visual interaktif.
- **Catatan Ringkas A4:** Siap cetak / simpan PDF (`Ctrl + P`) untuk belajar cepat sebelum ujian.
- **Naskah Asli PDF:** Tersedia di folder [`docs/uts-2024-pemrograman-visual.pdf`](docs/uts-2024-pemrograman-visual.pdf).

## Menambah soal

Tambahkan object baru ke salah satu file di folder [`questions/`](questions/). Setiap soal berisi `topic`, `q`, `options`, `answer`, dan `explain`. Tandai `challenge: true` untuk soal tantangan.
